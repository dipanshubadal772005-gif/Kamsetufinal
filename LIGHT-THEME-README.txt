KAMSETU COMPLETE LIGHT THEME
================================

This build applies the light blue/white KAMSETU design system globally.

Primary colors:
- #1683E8 primary blue
- #0B1F44 navy text
- #F5F9FD page background
- #FFFFFF cards
- #E2EAF3 borders
- #64748B secondary text

theme-light.css is injected as the final stylesheet on HTML pages so it
takes precedence over legacy page-specific styling.

No backend/API/database/route files were intentionally modified by the
theme conversion. Existing group-booking functionality from the source ZIP
is preserved.
